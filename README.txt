# Aesthetic Pink Personal Website ♡

## Files
- `index.html` — website structure/content
- `style.css` — all visual styling
- `script.js` — catalogue popup interaction
- `assets/` — put your own images here

## Replace these images
Put your images inside `assets/` with these exact names:
- `hero.svg`
- `item1.svg`
- `item2.svg`
- `item3.svg`
- `item4.svg`

## Before publishing
Open `index.html` and replace:
- `YOUR NAME`
- the About Me text
- catalogue names/descriptions/prices
- X / Telegram / WhatsApp links
- Rules & Info
- footer name

## Free hosting recommendation
Use GitHub Pages. Create a repository named:
`YOURUSERNAME.github.io`

Upload the files, then go to:
Settings → Pages → Deploy from branch → main → / (root)

Your site will be available at:
`https://YOURUSERNAME.github.io/`
